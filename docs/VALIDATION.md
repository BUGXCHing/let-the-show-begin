独立目录追加的玩法探针输出 `HAOXI_SMOKE_PASS`，但该次进程返回 1：Unity 编辑器启动时的 `UnityEditor.Search.SearchDatabase` 抛出索引越界异常，复查一次仍出现，严格的批处理检查将其记为失败。它不是本轮玩法代码的调用栈；仍保留此失败记录，不将该次额外运行标成全通过。证据保存在本机 `Logs/SourceRestore/`。原工程的正式玩法与动作批处理均返回 0。

### 代表性观测

- 走位测试移动 2.50 米，速度 4.35 米／秒；支撑脚目标滑移 0.000 米／tick，实际脚点有约束允许的误差，不宣称零滑步。
- 原地转动阶段换脚 23 次，累计转角约 881 度；最大可视骨长误差小于 0.0001 米，关节误差约 0.053 米；检测到的运行错误为 0。
- 死亡后保持倒地，重置后连接恢复；双触点、拾取／放下、颈部／手腕／膝盖损伤场景均通过。
- 玩法测试中的玩家扫掠被敌人兵刃格挡（1 次格挡、0 次穿过格挡的伤害）；另一个敌人挥击场景产生真实扫掠命中。隔离的轻重击与部位反馈场景使用直接受击注入，不能把它们说成摇杆瞄准测试。

## 不由这些测试保证的内容

- 本轮没有重新做手机／平板真机双指试玩，也没有完成所有浏览器和网络区域的兼容性测试。
- 动作自检验证稳定性与约束，不证明主观舞蹈美感；有限采样不保证所有极端帧率下都无漏判。
- 当前输入不能精确指定不同高度的关节；画面使用原有程序化灰盒角色、舞台和占位音效。
- 此轮测试未配置长期网站或 Unity 云端 CI；GitHub 源码发布不属于运行测试的验证范围。
