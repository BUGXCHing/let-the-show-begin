# 刀刃碰撞、部位与战斗反馈

## 1. 轨迹检测

`MeleeWeaponHitbox.FixedUpdate` 记录前后两次武器刚体的位置与旋转，将平移距离和旋转造成的刀尖弧长换算为采样数。当前步距约 0.085 m，每次最多 36 个切片。

每个切片用 `Lerp` 插值位置、`Slerp` 插值旋转，构造握柄前 0.24 m 到刀尖的刃部线段。对这条线段做 `OverlapCapsuleNonAlloc`，使用与武器类别对应的接触半径，扫描角色层和根节点层。

同一敌人可能同时被多个部位碰撞体覆盖。候选按距离、部位优先级排序，只保留该敌人的一个最合适接触部位。颈、腕、膝有小幅优先权，根节点碰撞体作为后备。

这能减少高速刀刃越过薄碰撞体而漏判，但仍是有限采样。非常极端的单步位移、超过固定 64 个碰撞候选的密集接触仍有边界；诊断中 `FullBuffers` 会记录缓冲区占满。

## 2. 武器格挡先于身体命中

每个切片先比较双方武器刃部线段的最近距离。当距离小于双方接触半径之和再加 0.045 m，且攻击刃速度超过最小值，记录该次挥动已被挡住。

同一 `SwingSequence` 对该防守者的身体伤害被抑制；双方武器获得阻滞与反向冲量，并发出格挡反馈事件。持握武器本身是 Trigger，格挡使用显式几何判断，而不是靠实体 Collider 把武器挤开。

## 3. 什么算一次有效攻击

沿接触点的实际运动计算：

```text
挥动速度 = [当前刃点 - 上次刃点 - 根节点位移] / fixedDeltaTime
有效速度 = dot(挥动速度 - 目标接触点速度, 挥动方向)
```

有效速度限制到不超过挥动速度的 1.5 倍，最终上限 9.5 m/s，避免关节投影纠正位置被误算成一击必杀。

- 低于 0.65 m/s 不伤害。
- 单纯走位、敌人撞上静止剑，不能作为挥刀刷伤害。
- 同方向持续贴刃不重复伤害；离开接触超过 0.095 秒或改变挥动方向才可形成下一次接触。
- 每个攻击方对目标，以及目标自身的受击接收，都有 0.25 秒冷却。
- 玩家主动牵引后保留短暂的惯性伤害窗口；敌人只在攻击阶段具有伤害资格。

## 4. 基础轻击、重击与击飞

`HitImpact.FromCollision` 首先计算：

```text
约化质量 = 武器质量 × 部位质量 / (武器质量 + 部位质量)
动量 = 约化质量 × 有效速度 × 接触位置系数
能量 = 0.5 × 约化质量 × 有效速度²
分档量 = 有效速度 × lerp(0.88, 1.10, 刃上接触比例)
基础伤害 = clamp(5 + 2.3 × 有效速度 + 1.25 × 能量, 6, 48)
```

这是游戏性近似，不是以真实牛顿单位还原组织损伤。`分档量` 小于 3.1 为轻击，3.1–6.4 为重击，大于等于 6.4 为击飞。

| 基础档位 | 行为 |
| --- | --- |
| 轻击 | 较小水平冲量；0.16 秒失控；0.035 秒短暂停顿；轻微镜头与音效。 |
| 重击 | 水平击退，通常不倒地；0.45 秒基础失控；0.065 秒短暂停顿。 |
| 击飞 | 水平冲量加向上速度变化；0.88 秒基础失控；0.09 秒短暂停顿，落地后倒地再起身。 |

最终效果还要经过受击角色的部位与攻方轻重击修正，不能只看 `HitImpact` 的基础分档。

## 5. 敌人抗击打与敌人的轻重击

攻击敌人时，头／颈允许在 6.5 m/s 以上保留击飞；膝为 9 m/s；普通身体／肢体为 9.3 m/s。未达部位门槛的基础击飞降为重击，清除向上冲量并缩短失控；伤害系数为头／颈 0.92、其他部位 0.72。

敌人攻击玩家有另一组基础伤害／冲量修正。AI 轻击强度为 0.85，会压制击飞、缩短失控；AI 重击强度为 1.4，有效速度达到 3.6 m/s 时可强制进入击飞反应。并不是所有敌人命中都会把玩家打倒。

初始玩家生命为 180，敌人生命为 200。死亡仍会倒地，即便最后一击是轻击；结算面板等待死亡姿势完成。

## 6. 关节累计损伤

`PuppetBodyPart.ZoneFor` 根据实际命中的碰撞体识别头、颈、腕、膝、肢体或身体；头上的额外球形碰撞体专门表示颈部。

```text
切割应力 = 锋利度 × max(0, 刃面朝向 - 0.22) × 速度 × 刃上接触系数
钝击应力 = 破坏系数 × 质量/(质量 + 0.65) × 速度 × 0.47
锋刃武器累计 = 切割应力 + 0.20 × 钝击应力
钝器累计 = 钝击应力
```

再乘攻方力量增益。颈、腕、膝的累计门槛分别为 7.8、6.2、8.3。超过门槛后解除对应物理关节，后代部位脱离程序肌肉控制；持武器的右腕断开会掉武器，敌人膝部破坏后走位速度降为原来的 28%，颈部破坏造成致命伤。

当前只有敌人会触发这些累计关节破坏。它已经实现碰撞和反应，但固定高度的右摇杆并不提供“指定砍膝盖／脖子”的精确交互；直接注入部位命中的测试证明规则可用，不等于普通玩家能稳定瞄准该部位。

## 7. 敌人策略与多人战斗

`EnemyTactics` 使用 Approach → Windup → Strike → Recovery 四阶段。接近时追击并侧移，过近时后退；观察玩家快速武器接近自己时短暂侧闪。

每次攻击递增计数。奇数次且玩家较慢、已受击或距离很近时选择重击，否则轻击；重击前摇 0.43 秒，轻击前摇 0.22 秒，攻击持续 0.28 秒，恢复 0.38 秒。冲击方向在起手时锁定，冲刺中仍由真实武器扫掠决定是否命中。

共享攻击槽和按敌人编号错开的侧移方向制造轮流／夹击机会；软排斥与根节点最小间距减轻堆叠。这是一套启发式行为，没有导航网格、行为树、学习模型或真正的多人战术规划。敌人之间不互相造成武器伤害。

## 8. 反馈、掉落与结算

一次 `HitImpact` 同时传给健康、失控、关节、镜头、音效与短暂停顿。根冲量使用 `VelocityChange` 让反应不被不同根质量稀释，部位冲量仍使用 `Impulse`。

击飞落地后短暂倒地并恢复，死亡关闭肌肉、释放骨盆根连接并保持物理倒地。敌人死亡或右腕破坏掉落武器；玩家双点右杆在 1.38 m 内选择最近的可拾取武器，重建对应的持握道具。

刀轨仅在可伤害且刃速足够时发出。木质击打声音由 `ImpactAudio` 合成，没有外部音频资源，也没有背景音乐。
