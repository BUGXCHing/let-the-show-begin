# 双摇杆、加速度与动作

## 左摇杆：移动地面根节点

入口是 `DualStickInput.Move → SetControls → UpdateMovement`。

```text
目标速度 = (左输入.x, 0, 左输入.y) × 玩家基础速度 × 增益 × (1 - 武器移动惩罚)
当前速度 = MoveTowards(当前速度, 目标速度, 移动加速度 × fixedDeltaTime)
下一位置 = 当前位置 + 当前速度 × fixedDeltaTime
```

输入被限制在单位圆，斜向不会更快。默认基础速度 4.35 m/s、加速度 29 m/s²；松杆、反向也用同一个加速度限制，不会直接清零速度。敌人的目标速度由 AI 给出，其加速度为 23 m/s²。

根位置限制在 X、Z 各 ±9.1 m，随后做角色最小间距修正，避免 kinematic 根互相穿入。修正后的实际位移重新计算 `motorVelocity`，供步态和武器相对速度使用。

受击时暂时让根变为动态刚体，移动代码不把冲量立刻覆盖掉。没有失控、倒地和腾空状态且稳定落地后，再接回地面控制。

## 右摇杆：指定角度，不是攻击按钮

入口是 `DualStickInput.Weapon → SetControls → SimulateWeapon`。

```text
目标偏航角 = atan2(右输入.x, 右输入.y)
角加速度 = 最短角度误差 × 刚度 - 当前角速度 × 阻尼
角速度 += 角加速度 × dt，并限制最大速度
轨道角 += 角速度 × dt，并环绕到 -180°…180°
```

角速度以度／秒维护；对 Rigidbody 施加力矩时换成弧度。使用 `DeltaAngle` 跨越 ±180°，避免一次普通转向突然绕完整圈。

右杆幅度超过 0.2 时更新目标角度，并将 `pull` 在约 0.1 秒内拉到 1；松杆则降到 0。**当前幅度主要是主动牵引门槛，没有连续映射为力度，也没有高度档位。** 角度变化产生的真实武器速度决定攻击强弱，不能把“右杆打满”直接理解为重击。

键盘方向键的输入还额外用 `Vector2.MoveTowards` 渐进到目标值：普通 ramp 为 3.3/s，Shift 为 11/s。鼠标把射线投到角色附近的水平面上，转换为相对角色的牵引方向。HUD 上开始的拖动不会变成舞台拖动。

## 武器刚体：握柄轨道与刀刃转动

目标握柄沿轨道角落在角色周围，半径约 0.54–0.72 m，目标高度默认 1.38 m。再从肩膀计算最大 0.85 m 的可达范围，避免把手臂拉到不可实现的位置。可达范围和关节约束会让实际握柄与目标有偏差；默认高度不是刚体 Y 轴硬锁。

握柄牵引使用位置弹簧：

```text
相对速度 = 武器线速度 - 根节点实际移动速度
牵引加速度 = (目标握柄 - 实际握柄) × 牵引刚度 - 相对速度 × 阻尼
```

再以目标武器旋转与当前旋转之间的四元数误差计算力矩。两种驱动均使用 `ForceMode.Acceleration`，并设加速度上限；质量仍影响接触冲量和伤害。每种武器的刚度、阻尼、转速、长度与质量见 `WeaponSpec`。

主动牵引时弹簧收紧；松杆时继续保留较松的目标牵引和重力，所以武器会拖曳／回摆，但不是彻底自由落下。玩家松杆后最多保留 0.52 秒合法惯性伤害窗口；静止贴住敌人仍不能刷伤害。

## 武器带动身体

`LateUpdate` 使用真实握柄与刀刃方向生成 Pose。主动牵引时向目标握柄预判最多 0.32 m，以提高响应。

- 握腕以 IK 贴近握柄，肩膀允许少量位置让步。
- 胸朝握柄方向转动，使用 73 刚度、14 阻尼和 540°/s 上限。
- 胯以更慢的 58 刚度、13 阻尼和 520°/s 上限追随，并参考走位方向。
- 胸胯角度差分配给腰和胸；倾斜、支撑侧、呼吸和受击姿势共同组成非对称 Pose。
- 空闲手通过延迟目标跟随身体，避免两只手同时僵硬摆动。

这条视觉因果链由程序化 Pose、IK 与受约束物理共同实现，不是引擎自动从碰撞推导整套舞蹈。

## 走路、跑步和旋转换脚

`PuppetRig.Gait.cs` 与 Pose 共用胸胯方向、实际速度和左右脚状态。

| 状态 | 实现 |
| --- | --- |
| 普通步行 | 预测角色下一段位移，交替抬脚到身体前方；支撑脚尽量保持世界位置。 |
| 跑步 | 速度超过 2.8 m/s 进入，降到 2.2 m/s 以下退出；滞回避免阈值附近抖动。两脚相差半个周期，短支撑、长腾空恢复。 |
| 武器带动原地转身 | 根据胸／胯角速度进入旋转混合；一个支撑脚转轴，另一个绕行落脚，落地后交换支撑。 |
| 走位同时旋转 | 混合步行和转身脚步，允许有限滑步以保持连贯。 |
| 腾空／倒地 | 暂停普通落脚，使用腾空或倒地脚目标，落地后恢复。 |

两段 IK 根据上下段长度和弯曲方向计算肘／膝，限制不可达目标；脚步超出腿的可达范围时允许小幅地面滑动。不是每一帧都绝对锁脚，目标是协调、稳定的演出。

## 物理与视觉混合

`PuppetDynamics` 让隐形关节刚体追逐 Pose 目标，并对目标速度做前馈和平滑。受击时短暂降低驱动力，使冲量可以传递。

完好身体只把有限的物理偏移混合到躯干，再解 IK 闭合四肢；断开的部位或死亡身体直接跟随真实刚体。`SaveTargets / RestoreTargets` 保存程序姿势，避免上一帧的物理偏移被反复叠加到新 Pose 上。

修改走速、角速度或武器长度时，请同时检查脚步的预判距离、支撑切换、手与握柄距离以及胸胯延迟，不能只看根节点跑得快不快。
